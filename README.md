# Kindle Lite OS

**0.1 Alpha** — предварительный релиз для разработки и тестирования.
Сборка проверялась только на Paperwhite 4 с FW 5.16.7 и уже установленными
jailbreak/USBNetLite/MRPI. Это новая пользовательская среда на штатном Linux,
а не образ прошивки. [Возможности и ограничения релиза](docs/releases/0.1-alpha.md).

Нативный C++17 прототип пользовательской среды для Kindle Paperwhite 4. **Работают интерфейс PW4, чтение TXT/EPUB/FB2 и текстовый HTTPS-браузер.** Автозапуск использует отдельный Upstart job; кнопка Amazon возвращает штатную среду. Ядро, загрузчик и разметка разделов остаются штатными. [Устройство, установка и восстановление](docs/current-device.md).

## Запуск на Windows

Нужны Visual Studio Build Tools 2019 или новее с компонентами Desktop development with C++ и CMake tools. VS Code: открыть эту папку, выполнить задачу **Run simulator**.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build.ps1 -Run
```

Параметр ExecutionPolicy действует только на запущенный процесс PowerShell. Скрипт находит CMake в PATH либо через vswhere, собирает Release и запускает CTest. На этом компьютере использован уже установленный MSVC 19.29 / Windows SDK 10.0.19041. WSL не установлен и для симулятора не нужен.

Готовое окно можно открыть напрямую: `build/Release/kindle_sim.exe`. Файлы книг находятся в `books/`, локальное состояние — в `runtime/`. Приложение ищет папку books рядом с exe и выше по дереву; для переносимой копии положите books рядом с exe. Папка должна быть доступна для записи. Запускайте только один экземпляр с одним каталогом состояния.

## Что реализовано

- Три раздела: библиотека, браузер, настройки. Чёрно-белое окно без анимаций, крупные кнопки.
- Явное обновление дискового каталога TXT/EPUB/FB2/PDF, поиск и сортировка по относительному пути, восемь книг на страницу. В RAM не загружается весь каталог.
- Чтение TXT и текстовый импорт EPUB/FB2 с сохранением позиции, одной закладкой на книгу и продолжением последней книги. EPUB следует порядку spine; FB2 читает body, поддерживает UTF-8 и Windows-1251. В Windows клавиша **B** возвращает к закладке.
- Размер шрифта и интервал, сохранение настроек. Wi-Fi и подсветка явно обозначены как **демо**; заряд батареи неизвестен.
- Windows-режим HTTPS-статей через WinHTTP: проверка сертификатов средствами ОС, до 2 МиБ, отдельный поток, ограниченные тайм-ауты, без JavaScript и фоновой загрузки ресурсов.
- Kindle-браузер: ввод HTTPS-адреса экранной клавиатурой, постраничное чтение, до 64 ссылок страницы, переходы и история сайтов. Сеть выполняется в отдельном процессе через системный curl с проверкой сертификата; до 2 МиБ и 25 секунд на запрос. Запрос отменяется при выходе или переходе в сон.
- CLI, CMake, тесты, конфигурация ARM-кросс-сборки с обязательным sysroot, read-only диагностика Kindle и инструменты измерений.

## Ограничения текущего прототипа

EPUB/FB2 отображаются как текст: без картинок, CSS, оглавления и переходов по сноскам. DRM не поддерживается. Импорт ограничен 16 МиБ текста; суммарное распакованное XML EPUB — 32 МиБ. PDF только индексируется. Названия берутся из имён файлов; автор и обложки отсутствуют. Поиск без учёта регистра относится к ASCII. Переносы выполняются по пробелам с разбивкой длинных слов по символам, без измерения глифов. TXT ожидается в UTF-8; UTF-16 пока не поддерживается.

Kindle-браузер отображает текст HTML и ссылки. Нет JavaScript, CSS, форм, авторизации, загрузки книг и картинок; работает только HTTPS и UTF-8/ASCII. Это первая версия браузера для простых страниц. Отдельный Windows-режим статей пока не имеет переходов по ссылкам; его старый HTML-парсер также имеет более ограниченное декодирование entities.

Backend PW4 использует FBInk и evdev. Каждое действие пока полностью обновляет экран. Служба powerd остаётся штатной; переход screenSaver → active и перерисовка после пробуждения проверены по USB. Глубокий сон без кабеля и длительная автономность не проверены. На PW4 прошли 51 проверка ядра, 12 проверок документов и 13 проверок web-парсера. Проверены также нативные сценарии чтения EPUB/FB2, браузера и возврата в Amazon. Превосходство по скорости и батарее ещё не измерено.

## Командная строка и проверки

```powershell
.\build\Release\kindle_cli.exe index books runtime/catalog
.\build\Release\kindle_cli.exe list runtime/catalog Welcome
.\build\Release\kindle_cli.exe read books/Welcome.txt
.\build\Release\browser_tests.exe --fetch
powershell -NoProfile -ExecutionPolicy Bypass -File tools/measure.ps1 -Seconds 15
```

Последний скрипт измеряет один уже работающий симулятор и пишет CSV. `--fetch` выполняет отдельный сетевой smoke test example.com; обычный CTest не зависит от интернета. `elapsed_us` CLI — длительность конкретной операции, не время появления окна.
