# Kindle Lite OS

**0.2 Alpha** — предварительный релиз для разработки и тестирования.
Сборка проверялась только на Paperwhite 4 с FW 5.16.7 и уже установленными
jailbreak/USBNetLite/MRPI. Это новая пользовательская среда на штатном Linux
с библиотекой, браузером и переходом в Amazon. [Установка и ограничения релиза](docs/releases/0.2-alpha.md).

Нативная оболочка C++17 для Kindle Paperwhite 4. Дополнительные движки обеспечивают **Chromium с JavaScript, CSS и изображениями** и чтение **EPUB/FB2 с оформлением и картинками**. Автозапуск открывает Kindle Lite при включении и перезагрузке. Кнопка Amazon переключает интерфейс, следующий цикл сна и пробуждения возвращает Kindle Lite. В верхней панели оболочки отображаются заряд и Wi-Fi. [Состояние разработки и проверки](docs/development-0.2.md).

Для установки скачайте PW4-архив из [релиза Alpha 0.2](https://github.com/Noki1945/kindle/releases/tag/v0.2.0-alpha). Большие движки подготавливаются отдельным скриптом с проверкой SHA-256, инструкции находятся в README архива. [Alpha 0.1](docs/releases/0.1-alpha.md) сохранена как предыдущая версия.

## Запуск на Windows

Нужны Visual Studio Build Tools 2019 или новее с компонентами Desktop development with C++ и CMake tools. VS Code: открыть эту папку, выполнить задачу **Run simulator**.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build.ps1 -Run
```

Параметр ExecutionPolicy действует только на запущенный процесс PowerShell. Скрипт находит CMake в PATH либо через vswhere, собирает Release и запускает CTest. На этом компьютере использован уже установленный MSVC 19.29 / Windows SDK 10.0.19041. WSL не установлен и для симулятора не нужен.

Готовое окно можно открыть напрямую: `build/Release/kindle_sim.exe`. Файлы книг находятся в `books/`, локальное состояние — в `runtime/`. Приложение ищет папку books рядом с exe и выше по дереву; для переносимой копии положите books рядом с exe. Папка должна быть доступна для записи. Запускайте только один экземпляр с одним каталогом состояния.

## Что реализовано

- Три раздела: библиотека, браузер, настройки. Чёрно-белое окно, крупные кнопки и карточки сайтов.
- Явное обновление дискового каталога TXT/EPUB/FB2/PDF, поиск и сортировка по относительному пути, восемь книг на страницу. В RAM не загружается весь каталог.
- Чтение TXT и EPUB/FB2 с сохранением позиции, закладкой и продолжением последней книги. На PW4 дополнительный движок Cool Reader поддерживает изображения, CSS и шрифты. Текстовый fallback читает EPUB по spine, FB2 в UTF-8 и Windows-1251. В Windows клавиша **B** возвращает к закладке.
- Размер шрифта, сохранение настроек и позиции после изменения размера. На PW4 заряд и Wi-Fi читаются из sysfs/procfs. Строка состояния обновляется отдельно от содержимого страницы. В Windows аппаратные настройки демонстрационные.
- Windows-режим HTTPS-статей через WinHTTP: проверка сертификатов средствами ОС, до 2 МиБ, отдельный поток, ограниченные тайм-ауты, без JavaScript и фоновой загрузки ресурсов.
- Полноценный браузер PW4 использует Chromium 149 в образе kbrowser и kview для экрана Kindle. Есть клавиатура, прокрутка, адресная строка, история, вкладки и загрузка файлов. Скачанные EPUB/FB2 попадают в books/Downloads, каталог обновляется после возвращения из браузера.
- Без образа Chromium доступен простой текстовый HTTPS-просмотр с системным curl, ограничением 2 МиБ и 25 секунд на запрос.
- CLI, CMake, тесты, конфигурация ARM-кросс-сборки с обязательным sysroot, read-only диагностика Kindle и инструменты измерений.

## Ограничения текущего прототипа

DRM не поддерживается. PDF только индексируется. Названия берутся из имён файлов; автор и обложки отсутствуют. Поиск без учёта регистра относится к ASCII. TXT ожидается в UTF-8. Для текстового fallback действуют ограничения 16 МиБ текста и 32 МиБ распакованного XML EPUB, оформление и изображения доступны через дополнительный движок.

Тяжёлые сайты расходуют много памяти и могут открываться медленно. Две недавние страницы сохраняются в RAM, более старые могут выгружаться. Введённый текст защищает вкладку от этой выгрузки. Проверка DeepSeek дошла до формы входа, работа ChatGPT/VPN отложена. Windows-режим статей использует собственный текстовый парсер и WinHTTP.

Backend PW4 использует FBInk и evdev. Основные страницы обновляются целиком, индикаторы используют свою небольшую область. Служба powerd управляет сном. Глубокий сон без кабеля и длительная автономность ещё не измерены. Проверяются Windows CTest, ARM-сборка и сценарии на настоящем PW4. Подробности находятся в [журнале разработки](docs/development-0.2.md).

## Командная строка и проверки

```powershell
.\build\Release\kindle_cli.exe index books runtime/catalog
.\build\Release\kindle_cli.exe list runtime/catalog Welcome
.\build\Release\kindle_cli.exe read books/Welcome.txt
.\build\Release\browser_tests.exe --fetch
powershell -NoProfile -ExecutionPolicy Bypass -File tools/measure.ps1 -Seconds 15
```

Последний скрипт измеряет один уже работающий симулятор и пишет CSV. `--fetch` выполняет отдельный сетевой smoke test example.com; обычный CTest не зависит от интернета. `elapsed_us` CLI — длительность конкретной операции, не время появления окна.
