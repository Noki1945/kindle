# Первый интерфейс PW4

`src/ui/kindle.cpp` использует переносимое ядро проекта, установленный FBInk из
MRPI KindleHF и системный шрифт Bookerly. Библиотеки FBInk и шрифты не включены
в репозиторий. Бинарник собран статически скриптом `scripts/build-arm.ps1`.

На проверенном PW4 используются goodix-ts и ABS_MT_POSITION_X/Y. Программа
проверяет имя устройства и диапазоны через ioctl перед захватом ввода. Координаты
соответствуют проверенной ориентации экрана этого экземпляра. Другие модели,
поворот экрана и сложные мультитач-жесты ещё требуют поддержки.

Проверены на устройстве отрисовка трёх разделов, изменение шрифта, открытие TXT
и восстановление lab126_gui после выхода и ошибки renderer. Снимок framebuffer
просмотрен на ПК, кириллица отображается. Проверка выполнялась программной подачей
координат в обработчик действий. Физическое касание вкладки настроек подтверждено
событиями goodix-ts и переходом раздела. Пользователь также подтвердил смену
текста при физическом перелистывании на устройстве.

Библиотека показывает восемь книг. TXT читается постранично, сохраняются позиция
и одна закладка на книгу. В настройках есть размер шрифта, продолжение последней
книги и переход к закладке. Строки переносятся по пробелам; слова длиннее строки
разбиваются по UTF-8 символам. Ширина пока оценивается числом символов, без
измерения глифов. Добавлены текстовый импорт EPUB/FB2 и HTTPS-браузер со
ссылками, историей и экранной клавиатурой: [current-device.md](current-device.md).

Запуск через `KindleLite-Start` в библиотеке либо `sh /mnt/us/kindle-lite/launch.sh`
по SSH. Оболочка временно останавливает lab126_gui и восстанавливает его через
trap. Кнопка **Amazon** расположена справа вверху. Обычный сеанс бессрочный;
только `--test-session` включает пяти минутное ограничение.
Ожидание ввода использует poll. В покое отрисовка отсутствует. Каждое действие
пока перерисовывает весь экран. Оптимизация частичных обновлений ещё впереди.

Добавлен отдельный Upstart job с одной попыткой на boot. Переход screenSaver →
active и перерисовка после пробуждения проверены по USB. Глубокий сон без кабеля
ещё не проверен. При неотвечающем интерфейсе можно завершить kindle_ui через SSH
сигналом TERM, launcher затем восстановит GUI. Для аварийного SIGKILL launcher
автоматическое восстановление не гарантируется.

Завершение kindle_ui сигналом TERM проверено на устройстве: процесс закрылся,
lab126_gui вернулся в start/running, каталог блокировки launcher удалён.
Сигналы обрабатываются через signalfd вместе с ожиданием касаний. У renderer
есть ограничение времени выполнения десять секунд.

На устройстве успешно выполнен `--smoke`: переход вперёд изменил позицию
с 0 на 267 байт, возврат назад восстановил 0, сохранённая закладка и её
открытие вернули 267. Проверяется сохранённое состояние, а не только отрисовка.
Тест завершился кодом 0 и восстановил lab126_gui. Эти координаты поданы
программно; это не проверка физических касаний кнопок чтения.

`assets/Welcome-Kindle.txt` — инструкция для устройства; при установке копируется
в `books/Welcome.txt` на Kindle. Файл `books/Welcome.txt` в репозитории относится
к Windows-прототипу.
