# Текущее состояние PW4 — 15 ноября 2026

> Автозапуск после настоящей перезагрузки подтверждён журналом, созданным в
> текущем boot: среда запустилась, зарегистрировала физические касания,
> открыла книгу и вернула Amazon после нажатия кнопки справа вверху.

Kindle Paperwhite 4, FW 5.16.7, Linux 4.1.15-lab126, ARMv7 hard-float.
Меняется пользовательская среда; ядро, загрузчик и драйверы остаются штатными.

## Чтение

Книги: `/mnt/us/kindle-lite/books`. «Обновить» перестраивает каталог.
TXT UTF-8 читается напрямую. С установленным движком из KOReader EPUB/FB2
отображаются через Cool Reader с CSS, изображениями и шрифтами. LuaJIT worker
передаёт готовую страницу нашей оболочке. Позиция и закладка содержат XPointer.
Загрузки браузера сохраняются в books/Downloads, изменение папки обновляет
каталог при следующем запуске оболочки.

Без движка EPUB/FB2 импортируются в текстовый кеш
`runtime/imported`, исходники не изменяются. EPUB следует порядку spine.
FB2 поддерживает UTF-8 и Windows-1251. Сохраняются текст, абзацы и XML entities.
В текстовом режиме оформление и изображения опускаются. DRM и PDF не реализованы.
Лимиты: XML одной главы/файла и итоговый текст до 16 МиБ,
суммарно распакованные XML EPUB до 32 МиБ, до 10000 ZIP members.
ZIP читается без распаковки в файловую систему; пути проверяются.
Кеш привязан к пути, размеру и времени изменения источника.

`Sample.epub` и `Sample.fb2` — собственные проверочные книги из assets/sample-books.
Создаются командой `document_tests --samples assets/sample-books`.

## Браузер

Полноценный браузер Chromium 149 использует kbrowser v0.1.3 и kview.
В нём доступны JavaScript, CSS, изображения, формы, клавиатура, история,
прокрутка, вкладки и скачивание файлов. Образ подключается через нижний FAT
mount /mnt/base-us. Запуск браузера завершает нашу оболочку, закрытие возвращает
её стартовую страницу браузера. Две недавние страницы сохраняются в RAM,
более старые могут выгружаться с защитой введённого текста.

При отсутствии образа доступен текстовый просмотр. «Браузер» → «Адрес»:
экранная латинская клавиатура, регистр abc/ABC, цифры,
символы URL, .com/.ru, стирание, очистка. «Открыть» загружает HTTPS-страницу.
«Ссылки» показывает до 64 ссылок, «Предыдущий сайт» возвращает по истории.
«Назад/Далее» перелистывают текст. Wi-Fi заранее настраивается через Amazon.

Системный curl запускается в отдельной группе процессов; проверка сертификатов
включена, редиректы только HTTPS, запрос до 25 секунд, соединение до 5 секунд,
тело до 2 МиБ. Выход и сон отменяют worker/curl. Поддерживается HTML/plain text
в UTF-8/ASCII. Нет JavaScript, CSS, форм, авторизации, загрузки книг и картинок.
Проверены HTTPS IANA, переход по ссылке на главную и возврат по истории.

## Запуск, сон и возврат

`sh /mnt/us/kindle-lite/launch.sh` либо KindleLite-Start в Amazon.
Обычный сеанс бессрочный; `--test-session` включает пяти минутный лимит.
Кнопка **Amazon** сохраняет позицию, освобождает сенсор и возвращает lab126_gui.

Системный Lua запускает power-bridge.lua: property frameworkStarted нужна powerd
при остановленном Amazon. Bridge завершается перед восстановлением Amazon.
Observer читает goingToScreenSaver/outOfScreenSaver, сохраняет позицию при сне
и перерисовывает UI при пробуждении. Переход screenSaver → active проверен по USB.
Глубокий сон без кабеля и длительная автономность ещё не проверены.

## Автозапуск и восстановление

`/etc/upstart/kindle-lite.conf` запускает среду после x. Ожидается готовность
blanket/powerd. Фиксированная задержка 15 секунд удалена. Upstart 0.6.6 не читает
.override, поэтому installer сохраняет оригиналы и комментирует start on
в lab126_gui.conf, otaupd.conf и otav3.conf. Явный запуск Amazon продолжает работать.
Guard /tmp/kindle-lite-boot-attempted ограничивает попытки начального запуска.

Отдельный kindle-lite-wake job наблюдает полный цикл goingToScreenSaver →
outOfScreenSaver. После выбора Amazon следующий такой цикл возвращает Kindle Lite.
Наличие launch.lock сохраняет уже открытую нашу сессию. Этот переход проверен
на устройстве с подключённым USB.

Верхняя панель читает процент/зарядку из bd71827_bat и Wi-Fi из sysfs/procfs.
При выключении Wi-Fi wlan0 исчезает, это учитывается. Таймер 60 секунд работает
во время бодрствования. Обновление индикаторов не перерисовывает область книги.

- «Настройки» → «Автозапуск» переключает autostart.enabled.
- Файл `/mnt/us/kindle-lite/SAFE_MODE` запрещает запуск независимо от настройки.
- Для выхода через SSH получить PID командой `pidof kindle_ui`, затем
  `kill -TERM PID`. BusyBox pkill -x на этом устройстве оказался ненадёжным.
- Для отмены прямого запуска выполнить disable-direct-boot.sh. Он отключает
  marker и восстанавливает оригинальный lab126_gui.conf из сохранённой копии.

scripts/kindle-install-autostart.sh копируется как install-autostart.sh,
config/kindle-lite.conf — как kindle-lite.conf. Также нужны wake.sh и
kindle-lite-wake.conf. Перед заменой job создаётся копия
в runtime/install-backup. Rootfs возвращается в ro. При тайм-ауте initctl reload
проверяется, что конкретный job существует через status kindle-lite.

## Подключение и сборка

scripts/kindle-ssh.ps1 использует USBNetLite, локальный ключ, отдельный known_hosts
и явно привязывает соединение к USB-адресу ПК.
PC 192.168.15.100/24, Kindle 192.168.15.244. Windows ifIndex может меняться:
искать адаптер по USB VID/PID. Парольный вход и SSH по Wi-Fi отключены.
USBNetLite auto включён для обслуживания; подключение сейчас работает как USB-сеть.
Возврат в режим диска доступен через KindleLite-USB-Toggle в Amazon.
USB mass storage одновременно с работой приложения не проверен.

scripts/build.ps1: Windows + CTest. scripts/build-arm.ps1: Zig 0.13.0,
статический musl/libc++, отдельная компиляция C-зависимостей.
TinyXML2/miniz включены с лицензиями; FBInk и Bookerly используются с устройства.
