# Состояние этапов

| Этап | Реализовано и проверено | Что осталось |
| --- | --- | --- |
| 1. Исследование | Первичные источники, архитектура, список неизвестных и рисков | Данные устройства, GPL firmware sources, точный SDK и jailbreak wizard |
| 2. Прототип | Windows-окно и нативный PW4-интерфейс, каталог, настройки, FBInk/evdev | Новый дизайн, метаданные и обложки, доступность кнопок |
| 3. Чтение | TXT, текст EPUB/FB2, Windows-1251 FB2, переносы слов, прогресс, закладка | Картинки/CSS/оглавление, PDF, качественная типографика, несколько закладок |
| 4. Оптимизация | Streaming каталог, ограниченная страница, ожидание событий; лог времени paint | Повторные замеры, частичные обновления, большой корпус, сравнение с Amazon |
| 5. Устройство | ARM, USB SSH/SFTP, FBInk/evdev, возврат Amazon, отдельный автозапуск с защитой от цикла | Длительная проверка, USB mass storage из новой среды, аварийное восстановление |
| 6. Питание | Штатный powerd, bridge готовности UI, события сна/wake, перерисовка после wake по USB | Глубокий сон без кабеля, Wi-Fi lifecycle, батарея и сравнение с Amazon |
| 7. Браузер | HTTPS на Kindle, ввод URL, ссылки, история, постраничное чтение, отдельный сетевой процесс | Формы, поиск, скачивание книг, JavaScript/CSS и полноценный движок |

Ближайшие шаги: расширить браузер, улучшить отображение EPUB/FB2 и дизайн,
проверить глубокий сон и оптимизировать обновления экрана.
Прототип работает на PW4; замена всей пользовательской среды ещё не завершена.
