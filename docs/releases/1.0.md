# Kindle Lite OS 1.0

[Схема системы и происхождение компонентов](https://github.com/Noki1945/kindle/blob/v1.0.0/docs/system-map.md).

Пользовательская среда для Kindle Paperwhite 4 / 10-го поколения с FW 5.16.7.
При включении и перезагрузке открывается Kindle Lite. Кнопка Amazon возвращает
штатный интерфейс, следующий цикл сна и пробуждения снова открывает Kindle Lite.

## Возможности PW4

- Библиотека TXT, EPUB и FB2 с сохранением позиции и закладки.
- Дополнительный движок Cool Reader отображает EPUB/FB2 с изображениями,
  оформлением CSS и встроенными шрифтами.
- Дополнительный браузер Chromium 149 поддерживает JavaScript, изображения,
  CSS, формы, адресную клавиатуру, прокрутку и вкладки.
- Стартовые кнопки Google, Алиса, DeepSeek, Pinterest, Wikipedia и ChatGPT.
- Загруженные браузером книги сохраняются в kindle-lite/books/Downloads.
  При возвращении в оболочку изменённая папка обновляет каталог.
- В верхней панели оболочки видны процент заряда, зарядка и состояние Wi-Fi.
  Показания обновляются раз в минуту при изменении данных, область обновления
  ограничена индикаторами. Во время сна таймер выключается.
- Браузер сохраняет две недавние страницы в памяти, старые страницы может
  выгрузить. Страницы с введённым текстом, закреплённые и звучащие вкладки
  сохраняются. Выгруженная вкладка загружается заново при открытии.

## Установка

Нужны уже работающие jailbreak, MRPI/FBInk, USBNetLite и SSH. Нативный backend
проверен на PW4 с goodix-ts. Для движков требуется примерно 1.5 ГБ свободного
места в пользовательской памяти. Архив релиза содержит оболочку и установочные
скрипты. Большие движки загружаются отдельно из закреплённых upstream-релизов
с проверкой SHA-256.

1. Распакуйте PW4-архив. Скопируйте kindle-lite в корень пользовательской
   памяти Kindle. При обновлении сохраните свои books и runtime.
2. Для полноценного браузера и книжного оформления запустите на Windows
   скрипт из распакованного пакета.

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File kindle-lite/scripts/prepare-optional-engines.ps1
   ```

   Он подготовит отдельную папку и выведет её путь. Скопируйте оттуда
   kindle-lite и kbrowser в корень пользовательской памяти Kindle.
   При обновлении сохраните существующий kbrowser.ext3 с профилем браузера.
3. В SSH на Kindle выполните настройку образа.

   ```sh
   cd /mnt/us/kindle-lite
   chmod 755 kindle_ui kindle_cli
   echo /usr/bin/python3 /mnt/us/kindle-lite/configure-browser.py | sh engines/browser/kbrowser.sh shell
   ```

4. При закрытой оболочке установите автозапуск и перезагрузите устройство.

   ```sh
   sh /mnt/us/kindle-lite/install-autostart.sh
   reboot
   ```

Перед обновлением запущенную оболочку можно закрыть кнопкой Amazon.
Без дополнительных движков доступны текстовый импорт EPUB/FB2 и простой
HTTPS-просмотр. Windows-архив содержит симулятор с текстовым чтением и WinHTTP.
Полноценные движки в этом релизе предназначены для PW4.
Для запуска Windows-симулятора нужен установленный Microsoft Visual C++ Runtime
с MSVCP140/VCRUNTIME140.

## Ограничения Alpha

Тяжёлые сайты требуют много памяти и могут открываться медленно. Совместимость
с каждым сайтом не гарантируется. На Kindle проверялись Google, страница входа
DeepSeek, Pinterest с изображениями и чат Алисы. Вход в учётную запись DeepSeek
и работа ChatGPT через VPN требуют отдельной проверки. VPN в эту сборку
не включён.

DRM не поддерживается, PDF пока только индексируется. В текстовом fallback
действуют прежние ограничения XML и объёма импорта. Длительная автономность
и глубокий сон без USB-кабеля ещё не измерены. Индикаторы относятся к оболочке
Kindle Lite, браузер использует собственный экран.

При последней контрольной перезагрузке USB/RNDIS определился в Windows,
а SSH-подключение не восстановилось. Служебный доступ после перезагрузки
нуждается в дальнейшей проверке. Прямой запуск библиотеки и переход из Amazon
после сна были подтверждены ранее на устройстве. Результаты проверок находятся
в [журнале разработки](https://github.com/Noki1945/kindle/blob/v1.0.0/docs/development-0.2.md).

## Восстановление

Файл /mnt/us/kindle-lite/SAFE_MODE отключает автоматический вход в новую среду.
Скрипт disable-direct-boot.sh возвращает штатный автоматический запуск Amazon.
Установщик сохраняет исходные Upstart-конфигурации в runtime/install-backup.

Лицензии встроенных библиотек находятся в licenses. Движки загружаются из
[kbrowser v0.1.3](https://github.com/vovnit/kbrowser/tree/v0.1.3) и
[KOReader v2026.07.1](https://github.com/koreader/koreader/tree/v2026.07.1).
