# Kindle Lite OS 0.1 Alpha

Предварительный релиз, тег `v0.1.0-alpha`. Проверен на одном Kindle Paperwhite 4
(10-е поколение), firmware 5.16.7. Не является образом прошивки: используется
штатное ядро Linux, драйверы и службы питания.

## Что работает

- Нативный интерфейс Kindle: библиотека, браузер и настройки.
- TXT UTF-8 и текст EPUB/FB2, порядок глав EPUB, UTF-8/Windows-1251 FB2.
- Перелистывание, размер шрифта, сохранение позиции и одной закладки.
- Текстовый HTTPS-браузер: экранная клавиатура, адреса, ссылки и история сайтов.
- Выход кнопкой Amazon; необязательный автозапуск с одной попыткой на загрузку.
- Штатный powerd: переход screenSaver/active и перерисовка после пробуждения.
- Windows-симулятор, CLI и тесты.

## Ограничения

EPUB/FB2 отображаются без картинок, CSS, оглавления и активных сносок. PDF пока
не читается. Браузер не поддерживает JavaScript, формы, авторизацию, загрузку
файлов и картинки. Требуется заранее настроенный Wi-Fi.
Каждое действие пока полностью обновляет экран. Типографика и дизайн предварительные.
Глубокий сон без USB, длительная автономность и прирост скорости относительно
Amazon не измерены. Поворот экрана и другие модели Kindle не проверены.

## Архивы

- `kindle-lite-0.1-alpha-pw4.zip`: папка kindle-lite, ARM-бинарники, скрипты,
  проверочные книги и инструкция ручного запуска. Автозапуск не включается
  простым копированием архива.
- `kindle-lite-0.1-alpha-windows-x64.zip`: симулятор, CLI, проверочные книги
  и инструкции. Может требоваться Microsoft Visual C++ Redistributable 2019/2022 x64.
- `SHA256SUMS.txt`: контрольные суммы архивов.
- Исходный код доступен в репозитории и стандартных source archives GitHub.

На Windows распаковать весь архив в доступную для записи папку и запустить
`kindle_sim.exe`. Каталог books должен оставаться рядом с exe.

## Ручной запуск PW4

Нужен уже работающий доступ к shell от root. Jailbreak в архив не включён.
Проверить модель/FW, сохранить пользовательские книги и убедиться, что возврат
к штатному интерфейсу доступен. Конкретная сборка требует этих установленных файлов:

```text
/mnt/us/extensions/MRInstaller/bin/KHF/fbink
/usr/java/lib/fonts/Bookerly-Regular.ttf
/usr/bin/lua и liblipclua
/usr/bin/curl
/dev/input/event2 с именем goodix-ts
```

Скопировать папку kindle-lite из архива в `/mnt/us/kindle-lite`, затем:

```sh
chmod +x /mnt/us/kindle-lite/kindle_ui /mnt/us/kindle-lite/kindle_cli
sh /mnt/us/kindle-lite/launch.sh
```

Книги положить в kindle-lite/books и нажать «Обновить». Кнопка Amazon возвращает
штатный интерфейс. При проблеме через SSH получить PID: `pidof kindle_ui`,
затем завершить его: `kill -TERM PID`. Не использовать SIGKILL для launcher,
если ожидается автоматический возврат в Amazon.

Для необязательного автозапуска после успешного ручного теста:

```sh
sh /mnt/us/kindle-lite/install-autostart.sh
```

Установщик добавляет `/etc/upstart/kindle-lite.conf`, сохраняет предыдущую копию
при наличии и возвращает rootfs в ro. Через 15 секунд после запуска штатного GUI
открывается новая среда. Кнопка Amazon не вызывает повторный вход в этом boot.
Отключить можно в настройках или файлом `/mnt/us/kindle-lite/SAFE_MODE`.
Удаление одного дополнительного Upstart job не требует перепрошивки ядра.

## Проверка

Windows CTest: 4/4. На PW4: 51 core, 12 document, 13 web checks.
Проверены сценарии EPUB/FB2, HTTPS IANA, переход по ссылке и история,
экранная клавиатура, автозапуск после перезагрузки и физический выход в Amazon.
Проверки сна проведены при подключённом USB; это не проверка глубокой автономности.
Подробности: [validation.md](../validation.md), [current-device.md](../current-device.md).

TinyXML2/miniz и лицензии включены. FBInk, Bookerly, jailbreak, прошивка Amazon,
ключи, резервные копии и личные книги в релиз не входят.
