Параметры прототипа сохраняются в `runtime/state/settings`, прогресс — в отдельных файлах по идентификатору пути книги. Формат внутренний, версия 0.1. Включение Wi-Fi и подсветка являются только демонстрацией. Настройки аппаратных интерфейсов пока отсутствуют: нельзя подставлять предполагаемые пути устройств.
